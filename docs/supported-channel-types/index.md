## Supported channel types
Here's a list of channel types that are currently supported by selfbot-ts

| type | class | description |
| --- | --- | --- |
| 0 | GuildTextChannel | A text channel within a guild |
| 1 | DMChannel | A dm with a single user |
| 3 | DMChannel | A group dm chat with multiple recipients |
| 5 | GuildTextChannel | A guild new channel, similar to a normal text channel |

## Not supported yet

guild voice (2),
guild category (4),
guild store (6),
news thread (10),
public thread (11),
private thread (12),
guild stage voice (13),
guild directory (14),
guild forum (15),
guild media (16),
lobby (17),
dm (18)
